## ⚙️ Технологии и CI/CD

Проект настроен с использованием современных стандартов DevOps для учебных проектов:

*   HTML5 & CSS3 — семантическая разметка и красивый дизайн с анимациями.

*    JavaScript (ES6+) — интерактивность сайта и игровая логика.

*   GitHub Actions — автоматическая сборка и непрерывная доставка (CD) при каждом пуше в ветку main.

*   GitHub Pages & Environments — безопасное развертывание приложения с историей статусов деплоя в реальном времени.
